Island kit

Generate the models that make the map itself look professional: one island base plus one landmark for each place ({{ kit|length }} models). Until a model is published, the map keeps its built-in look, so you can do this piece by piece. Each piece goes to review first; publish the ones you like.

Option 1: upload one model (free, from Blender)

Made an island or landmark in Blender? Export it as glTF Binary (.glb) and upload it here. No AI credits are used. It goes live in My World straight away (untick the first box below to keep it for review instead), and you can still preview, Unpublish or Delete it afterwards. Choose Island piece: Island base for the big island itself, or a place (Home, Pictures, Videos...) for the landmark that stands on it.

You can upload many island bases. Each published one appears by this name in World settings > Island look, and people choose the one they like. With none chosen, the newest is used.

Option 2: upload a whole folder (free, from Blender)

Export all your models as glTF Binary (.glb) into one folder, then choose that folder here. Every .glb inside it (subfolders too) is checked and added, up to {{ folder_max_files }} at a time. Each file is matched to its place by its file name: island_base.glb (or island.glb), home.glb, pictures.glb, videos.glb, shorts.glb, music.glb, sports.glb, food.glb, colors.glb, nature.glb, animals.glb, vehicles.glb, art.glb. Item names such as cupcake.glb work too. A file whose name does not match is skipped and listed, and the rest are still added. No AI credits are used.

Picking one kind instead of matching by name makes every file that kind, named after its file. Handy for uploading many island looks at once.
